# Тестовое задание: два макета

Вёрстка двух макетов из Figma в одном проекте. Стек: HTML, CSS, JavaScript без фреймворков и сборщиков.

| Задание | Папка | Статус |
|---|---|---|
| 01 · Светлый Дом (лендинг «Додзё Медиа») | `svetly-dom/` | готово |
| 02 · Услуги и форма записи | `services/` | готово |

## Как запустить

Откройте проект через локальный сервер, например:

```bash
python -m http.server 8000
```

и перейдите на `http://localhost:8000/`: там ссылки на обе страницы. Можно также использовать Live Server в VS Code.

Если открыть `index.html` двойным кликом, Chrome может не загрузить шрифты: он блокирует их для адресов `file://`. На GitHub Pages и локальном сервере всё работает.

## 01 · Светлый Дом

Что сделано:

- десктоп 1440 px и мобильная версия 390 px по макету, плавный адаптив между ними;
- мобильное меню (кнопка 44×44, закрывается по Esc, по клику на пункт и при переходе на десктоп);
- состояния default, hover и focus-visible для кнопок, карточек, навигации и email — значения из фрейма «Компоненты и состояния»;
- карточка проекта целиком одна ссылка, без вложенных ссылок и кнопок;
- шрифты Oranienbaum и Manrope подключены локально (только кириллица и латиница), изображения переведены в WebP: около 420 КБ вместо 6 МБ;
- семантика и доступность: skip-link, `aria-expanded` у меню, alt у изображений, видимый фокус с клавиатуры, учёт `prefers-reduced-motion`.

### Допущения

- **Форма «Обсудить проект».** В макете кнопка есть, а формы нет. Сделал модальное окно (`<dialog>`) с полями «Имя», «Email» и «О задаче», валидацией и состоянием успешной отправки. Данные никуда не отправляются.
- **Цвет ошибки.** В токенах его нет, добавил `#9E2A2B` в той же приглушённой гамме.
- **Пункт «Подход».** Отдельного раздела в макете нет, ссылка ведёт на первый экран с описанием подхода.
- **Ссылки карточек.** Страниц кейсов в макете нет, ссылки ведут на якоря-заглушки.
- **Планшет (768–1023 px).** Макета нет: заголовок и описание идут в одну колонку, карточки в две.
- **Размер заголовков.** H1 и H2 плавно меняются между мобильным и десктопным значением из токенов (44→72 и 32→48 px).
- **Логотип.** В токенах размера нет, по макету подобран 32 px.

## 02 · Услуги и форма записи

Что сделано:

- десктоп 1440 px и мобильная версия 390 px, размеры и отступы сверены с макетом;
- лента услуг листается свайпом, тачпадом и перетаскиванием мышью, с привязкой к карточкам (scroll-snap);
- форма карточки с вырезом под кнопки повторяет макет: контур снят с экспорта из Figma и задан SVG-маской;
- фигурный фон формы со срезами под 45° строится в JS через `clip-path: path()` по реальному размеру блока, поэтому диагонали не искажаются на любой ширине;
- валидация формы: ФИО (только буквы, пробел, дефис), телефон с маской `+7 (999) 999-99-99` (ввод с 8 тоже работает), обязательное согласие; ошибки под полями, фокус на первое неверное поле, состояние успешной отправки;
- кнопка «Консультация» прокручивает к форме, ставит фокус в поле ФИО и запоминает услугу, она попадает в сообщение об успехе.

### Допущения

- **Шрифт.** Название шрифта в макете не проверено, по ширине надписей подобран Montserrat (400, 500, 600): ширина надписей совпадает с макетом.
- **Карточка «Терапия».** В макете видна только её левая часть. Собрал по аналогии с «Имплантацией»: тёмный фон и стоматологическое зеркало, положение и наклон подогнаны под видимый фрагмент.
- **Состояния.** Hover и focus в этом макете не показаны: кнопки при наведении становятся синими, фокус — бирюзовая обводка, поля с ошибкой — красная рамка.
- **Чекбокс согласия** по умолчанию не отмечен: согласие на обработку персональных данных должно быть активным действием. В макете показано отмеченное состояние, оно повторено как checked.
- **Полоса прокрутки** ленты скрыта, как в макете. Что ленту можно листать, показывает обрезанная четвёртая карточка.
- **Планшет (768–1199 px).** Макета нет: форма раскладывается в колонку, как на мобильном, карточки — десктопного размера.
- **Стрелка в карточке** ведёт на якорь-заглушку: страниц услуг в макете нет. Ссылка на политику обработки данных тоже заглушка.
